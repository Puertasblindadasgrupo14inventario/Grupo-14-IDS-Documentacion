# Puertas Blindadas ERP — Módulo Inventario (documentación)
**Grupo 14 · Ingeniería de Software · Scrum++**

Sistema ERP para una fábrica de puertas blindadas. Este repositorio reúne la **documentación de cada entrega** del
Módulo de Inventario, uno de los tres módulos del sistema (Inventario, Terreno y Finanzas).

El código del sistema (base de datos, backend y frontend) y las instrucciones para instalarlo están en el repositorio
[Grupo-14-IDS-Codigo](https://github.com/Puertasblindadasgrupo14inventario/Grupo-14-IDS-Codigo).

## Contenido de cada entrega

### Documento 0

Levantamiento inicial del proyecto, antes de empezar a desarrollar.

| Contenido | Archivos |
|---|---|
| Presentación | `Documento 0 - Grupo 14.pptx` |
| Proceso actual de la empresa (Bizagi) | `Bizagi/` |
| Requerimientos y casos de uso | `Requerimientos UR - Grupo 14.xlsx`, `Casos de Uso - Grupo 14.xlsx`, `Matriz de Requerimientos vs Casos de Uso - Grupo 14.xlsx` |
| Diagramas de casos de uso | `Diagrama CU/` (drawio e imágenes, por actor) |
| Dimensión técnica y arquitectura (MVC) | `Dimensión Técnica del proyecto - Grupo 14.docx`, `MVC - Grupo 14.drawio` |
| Estimación de costos y beneficios | `Estimación de costos y beneficios - Grupo 14.xlsx`, análisis cualitativo y cuantitativo |
| Organización del trabajo | `Organizacion Trabajo- Grupo 14.xlsx` |
| Aceptación del cliente | `CorreoAceptacionUsuario.png` |
| Currículum de los integrantes | `Curriculum/` |

### Incrementos 1 a 4

Cada carpeta de incremento sigue la misma organización:

| Contenido | Dónde |
|---|---|
| Presentación del incremento y sus anexos | `Incremento N - Grupo 14.pptx`, `Incremento N - Anexos - Grupo 14.pptx` |
| Requerimientos de usuario y casos de uso | Planillas de requerimientos (UR) y de casos de uso |
| Planificación Scrum | Product Backlog, Sprint Backlog, organización del trabajo y gráficos Burn down / Burn up |
| Diagramas de casos de uso | `Diagrama(s) CU incremento N/` (drawio e imágenes, por actor: Gerencia y JOP) |
| Diagramas de secuencia | `Diagramas de secuencia/` |
| Modelo de datos | MERE y modelo físico (drawio e imagen) |
| Arquitectura | Diagrama de componentes, diagrama de despliegue y árbol de navegación |
| Pruebas del sistema | `Pruebas del sistema/`: iteraciones de pruebas de caja negra |
| Vistas del sistema | Capturas de las pantallas (`Vistas pagina web - Grupo 14/` en los incrementos 1 y 2, `Vistas del sistema/` en el 3 y el 4) |
| Documento de instalación | `Incremento N ... Documento de instalacion.docx` |

Además:

- **Incremento 1:** videos explicativos de la instalación y de las funcionalidades (`Videos explicativos/`).
- **Incremento 3:** documento del incremento (`Incremento 3 - Grupo 14.docx`).
- **Incremento 4:** proceso de la empresa actualizado (`Bizagi/`), estimación de costos y beneficios actualizada y
  carta de aceptación del cliente (`Carta de Aceptación_ALPA Comercial Ingenieria.pdf`).

## Instalación del sistema

Los pasos para instalar y ejecutar el sistema están en el README del repositorio
[Grupo-14-IDS-Codigo](https://github.com/Puertasblindadasgrupo14inventario/Grupo-14-IDS-Codigo). El documento de
instalación de cada incremento queda en su carpeta; el vigente es el del **Incremento 4**.

---

## Metodología

**Scrum++** con dos semestres de desarrollo iterativo, en cuatro incrementos. Cada incremento cierra con iteraciones
de pruebas de caja negra sobre el sistema completo.
